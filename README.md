## 2. 与 1 组的关系

1 组负责需求调研，并额外交付了一套需求建模基线。2 组在其基线上开展建模迭代。

- 1 组仓库：`https://github.com/Aut-172/Intelligent-Reader`
- 2 组仓库（本仓库）：`https://github.com/<待填写>/Intelligent-Reader-2zu`
- 1 组基线快照见 [`baseline-from-1组/`](./baseline-from-1组/README.md)（来源提交 `899957a`），**只读，不修改**。

两组的区分度：课程要求两组采用不同的大模型、提示词、技术路线与迭代过程，本仓库的实现与 1 组相互独立。
