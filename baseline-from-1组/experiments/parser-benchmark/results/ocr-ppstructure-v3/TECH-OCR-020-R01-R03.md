# TECH-OCR-020 PP-StructureV3 本地版面/表格实验

> 这是两张项目自制页面上的可运行性、结构和故障定位实验。双栏表格页有人工表格真值；扫描页只有文本真值。它不是复杂表格、印章、手写或公式质量结论。

## 环境和配置

- Python `3.11.16`；PaddlePaddle `3.3.1`；PaddleOCR `3.7.0`
- `SELF-004` 源 PDF SHA-256：`ab008a1879ed22c5f92abe0dab30f1bbd2ffe2e462b1b2c25ec55cc7fa03fa63`；逐页 JSON 另存实际输入图像哈希
- 安装扩展：`paddleocr[doc-parser]`
- CPU；`enable_mkldnn=false`；文档方向、去畸变、文本行方向、印章、公式、图表和区域检测关闭
- 表格识别开启；表格方向分类关闭，避免获取本实验不需要的额外方向模型
- 项目内模型缓存共 48 个文件、`944,516,233` 字节，约 `901 MiB`
- Windows 中文用户名下必须把 `PADDLE_PDX_CACHE_HOME` 指向项目 ASCII 路径；同一进程需先导入 PyTorch，再导入 Paddle/PaddleOCR

## R01：默认 OneDNN 路径失败

模型初始化约 `94.5 s`，两页均在约 `0.15 s` 内触发 Paddle OneDNN 执行器 `ConvertPirAttribute2RuntimeAttribute` 异常。未进入有效页面推理，不能形成识别质量结论。原始结果为 `result-R01.json` 和 `*-R01.json`。

## R02：关闭 MKL-DNN 后的原尺寸结果

| 页面 | 输入尺寸 | 结果 | 端到端页面时延 | 结构观察 |
|---|---:|---|---:|---|
| `SELF-002` 第 1 页 | 993x1404 | 成功 | `823.1 s` | 15 个解析块；11 个有阅读顺序；表格、脚注和两个页脚没有 `block_order` |
| `SELF-004` 第 1 页 | 1588x2246 | 原生进程退出 | 未取得可分离页时延 | 多页运行和独立进程重试均以退出码 1 结束，没有 Python traceback 或页面 JSON |

`SELF-002` 布局检测返回 `table:1`、`text:7`、`paragraph_title:5`、`footer:2`、`reference:1`。正文总体按左栏后右栏排列，页脚未混入有序正文；但表格和脚注没有进入完整的块顺序，因此不能把 `block_order` 当作所有页面元素的全序。

表格检测恢复了正确的 3x3 网格和 9 个单元格框，但 HTML 只有 5/9 个单元格内容位于正确位置：

```text
字段 | 示例值 | 风险
physical_page 2 | [空] | 封面导致打印页码偏移
[空] | [空] | 标题层级可能被误判
```

普通表格 OCR 中仍能看到 `heading_path 1 > 2`，说明字符识别结果在，但结构匹配阶段丢失或合并了单元格。表格框数量、OCR 高置信度和正确行列数都不能替代单元格位置准确率。

## R03：缩小扫描页诊断

将同一 `SELF-004` 第 1 页保持纵横比缩小到 1000x1414 后，独立进程成功：

- 缓存模型初始化约 `9.79 s`；页面推理约 `118.59 s`
- 全字符 CER `0.60%`；中文 CER `0`；英文/数字 WER `33.33%`
- 9 个关键字符串全部命中；10 个 OCR 行框覆盖率 `1.0`
- 布局只有 `text:7`、`paragraph_title:1`；页脚被当作正文文本
- 未检测到表格；该页的 `A-01 / 0.95 / 表格候选单元格` 只是空格分隔候选行，不是带网格表格

R03 证明扫描内容可被该模型识别，也说明原尺寸失败与输入尺寸或运行资源有关；但缩小变体不能替代原分辨率质量结果，也不能证明生产中任意大页稳定。

## 项目结论

- PP-StructureV3 已解决 V2 表格子模型无法初始化的问题，并能输出布局 bbox、解析块、表格 HTML、单元格框和 OCR 结果。
- 当前 Windows CPU 路径不适合作为一期同步主链路：双栏表格页约 13.7 分钟，模型缓存约 901 MiB，原尺寸扫描页可复现原生退出。
- 即使页面处理成功，阅读顺序仍不覆盖表格/脚注/页脚，表格内容位置准确率只有 5/9；必须保留表格原图和普通 OCR，结构结果标记为 `table_uncertain`。
- 一期应继续以轻量本地 OCR 作为基础文本链路。V3 只适合离线异步增强实验；在完成页级隔离、输入尺寸门控、超时/内存限制和真实表格集验证前，不进入默认路径。
- 印章、手写、公式和特殊符号仍未验证；配置项存在不等于项目支持。

原始结果：`result-R01.json`、`result-R02.json`、`result-R03.json`、逐页 JSON 和 `score-summary.json`。复现脚本：`scripts/run_ppstructure_v3.py`；评分脚本：`scripts/score_ppstructure_v3.py`；依赖：`requirements-paddle3.txt`。
