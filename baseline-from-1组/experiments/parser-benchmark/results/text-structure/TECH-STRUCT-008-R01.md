# TECH-STRUCT-008-R01 结构结果下游定位检查

日期：2026-09-29  
范围：固定查询命中后的标题路径、源位置、页码/bbox 和表格/公式类型保留；不测试向量检索或问答模型。

## 1. 指标定义

- `query_recall`：固定查询和人工证据片段中，至少命中一个 IR 元素的比例。
- `heading_path_retention`：命中元素中保留非空标题路径的比例。
- `location_retention`：命中元素中保留可回溯位置的比例：PDF 为页码+bbox，Markdown/TXT 为源行，HTML 为 DOM selector。
- `is_table_or_equation`：命中是否仍被识别为表格/单元格/公式，而不是普通段落。

这些指标只检查结构结果是否能支撑证据回溯，不代表检索排序、答案正确率或引用内容正确率。

## 3. 发现

1. “能搜到文本”与“能支持导航/引用”仍然不同。修正 table/cell 标题路径继承并加入保守公式子元素后，Docling 三份 PDF 查询召回、标题路径保留和位置保留均为 1.0；公式语义仍未验证。
2. Markdown 扩展结果已经可以把表格和脚注作为独立元素，并使用源行完成引用回溯；这适合做一期结构 IR 的回归基线。
3. 表格单元格的标题路径必须从 table 父节点继承，不能只按单元格自身文本匹配；该规则已加入当前 Docling 映射。
4. HTML 已接入 `SELF-012` 固定查询，三项下游指标均为 1.0；但该结果只适用于静态快照，不覆盖动态渲染、shadow DOM、iframe 和版本漂移。

## 4. 对产品能力的直接影响

- 目录点击：命中 heading 或带 `heading_path` 的段落时可以导航；只有页码/bbox 没有路径时只能定位页面，不能准确展开章节。
- 段落检索：结果必须携带 `heading_path` 和 `element_type`，否则表格/公式会被错误当作普通段落。
- 问答证据：表格、脚注和公式命中时应保留专用类型并提示证据形态；不能只输出线性文本。
- 引用定位：PDF 采用 `physical_page + bbox`，Markdown 采用源行，HTML 采用 selector/anchor；不同格式不能强行共用页码字段。
