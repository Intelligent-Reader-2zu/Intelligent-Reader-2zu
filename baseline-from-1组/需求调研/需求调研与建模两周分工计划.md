# 智能阅读器需求调研与建模两周分工计划

> 本文档用于查看两周排期和人员安排。各任务的详细工作内容、记录字段和验收方法见 [需求调研与建模任务执行参考.md](C:/Users/联想/Desktop/note/学生笔记/软件系统分析与设计/需求调研与建模任务执行参考.md)。

## 一、执行原则

- 第 1 周完成需求建模所需的最小前置成果，不要求全部调研结束。
- 第 2 周调研与需求建模并行推进，调研证据持续反馈并修订模型。
- 每项任务标注一名主负责人，参与人负责执行、记录、审核或提供专业输入。
- 任务编号沿用需求调研任务包：`T` 表示调研任务，`M` 表示建模任务。

## 二、成员职责

| 成员 | 主要职责 |
|---|---|
| A | 总负责人；技术验证、模型方案、数据合规、需求综合、模型评审和最终报告 |
| B | 招募与访谈执行；学生、教师等用户访谈；参与者预约和记录管理 |
| C | 用户研究与可用性测试；科研人员、办公用户等访谈；测试主持和证据编码 |
| D | 场景与用户任务分析；竞品分析；低保真/可点击原型；功能优先级建议 |

## 五、关键承继关系

```text
T01 → T02 → T03/T04/T06/T07
T03 + T04 + T07 → T05 场景与用户任务
T05 + T06 + T07 → T08 原型
M0 → M1 → M2 → M3 → M4 → M5
T08 + T03 → T09 可用性测试
T03 + T05 + T06 + T07 + T09 → T10 需求优先级
T10 + M4 → T11 报告与归档
```
