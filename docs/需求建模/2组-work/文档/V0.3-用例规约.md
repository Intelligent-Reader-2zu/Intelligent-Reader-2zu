## 0. 阅读说明

1 组基线中，用例只以两种形式存在：V0.2 §5 的**一张清单表**（12 行，列出参与者/前置/结果/异常），和 SRS §4 的 **5 条一句话简述**（UC01/UC02/UC05/UC06/UC07/UC08/UC09+10）。两者都不是可执行的用例规约——没有编号化的主成功路径，也没有把异常路径落到冻结的状态名上。

本文件补这一块：以 **UC01 为格式标杆**完整填写，其余 11 条给出字段骨架，字段内容取自 V0.2 §5 与 SRS，不新增语义。待补字段统一标注 `【待补】` 并注明补写依据。

**编号与状态名一律取自《编号规则与术语表》**，不得自造。

## 2. UC01 导入文档（完整样例）

| 项 | 内容 |
|---|---|
| 用例编号 | `UC01` |
| 用例名称 | 导入文档 |
| 主要参与者 | Reader |
| 前置条件 | 用户已进入工作区；文档库可用 |
| 触发事件 | 用户在文档库中选择"导入"并明确选定文件 |

**主成功路径**

1. 用户明确选择一个或多个文件（系统不遍历目录、不自动读取工作区，BR11）。
2. 系统校验文件格式与访问权限。
3. 系统计算 `source_hash`，登记 `Document` 与 `DocumentVersion`；若同一 `source_hash` 已存在有效版本，则不重复创建（SPEC §3.2）。
4. 系统创建 `ParseRun`，文档状态置为 `registered` 后进入 `queued`。
5. 系统向用户返回 `document_id`、`version_id`、`parse_run_id`（SPEC §7 `/documents/import`）。
6. 系统生成导入完成通知（`Notification`）。

**异常与降级路径**

| 编号 | 触发条件 | 系统响应 | 结果状态 |
|---|---|---|---|
| 1a | 格式不支持 | 明确提示不支持及原因，不读入其他文件 | 不创建版本 |
| 1b | 权限不足 | 提示权限原因，不读入其他文件 | 不创建版本 |
| 3a | 同一 `source_hash` 已存在有效版本 | 不重复创建，提示已存在并定位到既有版本 | 复用既有 `DocumentVersion` |
| 4a | 解析任务创建失败 | 记录错误码，提示可重试或删除任务 | `ParseRun.status = failed` |

**后置条件**：`Document`、`DocumentVersion`、`ParseRun` 存在且状态可查；源文件保持只读未修改。

**关联**

- 业务规则：BR11、BR14
- 功能需求：FR-01
- 非功能需求：NFR-05（溯源字段）、NFR-13（格式优先级与明确提示）
- 领域对象：Document、DocumentVersion、ParseRun、Notification
- 图：A5（时序图·导入-解析-索引）、A1（状态图·文档处理）、用例图 UC01

### UC05 检索文档或授权文档集

| 项 | 内容 |
|---|---|
| 主要参与者 | Reader |
| 前置条件 | 文档已索引且用户有权访问 |
| 触发事件 | 用户提交检索词或模糊问题 |
| 主成功路径 | 1 选择范围 → 2 权限过滤（BR01）→ 3 全文/语义/混合检索 → 4 按来源分组返回结果与位置 |
| 异常与降级路径 | 权限过滤后为空 → 返回无答案并提示调整范围（BR04）；结果噪声；来源版本失效 → `stale` |

| 关联 | BR01、BR04；FR-03；NFR-02；Query、DocumentSet、Index；A6 |

### UC06 对当前文档/选中文本提问

| 项 | 内容 |
|---|---|
