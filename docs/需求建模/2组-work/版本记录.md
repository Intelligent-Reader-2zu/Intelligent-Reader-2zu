## 5. 版本号约定

| 版本段 | 含义 |
|---|---|
| V0.x | 需求模型的工作版本（调研/建模期迭代） |
| V1.x | 已成文的规格类文档（SRS、SPEC） |
| V1.0 → V1.1 | 内容修订、结构不变 |
| V1.0 → V2.0 | 范围或结构重大变化 |
