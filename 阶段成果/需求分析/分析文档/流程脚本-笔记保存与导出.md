# 笔记保存与导出流程脚本 v1

对应工作包：W6。本稿以《02-关键流程文字脚本-v0.1》§3 为底稿，按《01-业务对象清单-v0.1》BO-14～BO-20 与《04-模型一致性检查表-v0.2》§4 补齐笔记落库、引用核验与导出／分享约束。项目名称统一为“智能笔记助手”。

## 1. 范围与参与者

- 用户从原文选区或回答结论发起“保存为笔记”；保存成功后再按笔记范围发起导出或分享。
- 笔记控制器协调内容块（定位校验）、笔记模板、笔记、批注、标签、引用、回答结果、分享链接与通知。
- 笔记界面是边界对象；分享范围受权限规则约束，本流程不展开权限实现。
- 本流程止于“笔记落库 + 分享链接生成”。检索请求的发起与结果返回属于图 4。

## 2. 主成功路径（消息编号与图一一对应）

| 编号 | 消息／动作 | 结果 |
|---|---|---|
| M01 | 用户在原文中选中内容，发起“保存为笔记” | 形成保存意图 |
| M02 | 笔记界面提交保存意图（选区、原文定位、可选模板） | 笔记控制器受理 |
| M03 | 笔记控制器向内容块校验原文定位 | 定位有效／失效 |
| M06 | 读取笔记模板字段与输出格式；无模板取默认 | 确定笔记字段 |
| M08 | 创建笔记（正文、类型、定位锚点） | 笔记对象落库 |
| M09 | 按需写入批注 | 批注锚定原文或回答 |
| M10 | 绑定标签 | 支撑后续按标签组织 |
| M11 | 关联引用 | 笔记可回到原文证据 |
| M12–M13 | 若笔记引用回答结论，则由引用核验结论来源与定位 | 引用可回溯 |
| M14–M15 | 生成保存成功通知 | 用户确认笔记已保存 |
| M16–M19 | 用户选择笔记范围发起导出／分享，收集笔记、批注、标签并汇总引用与定位 | 导出内容固定 |
| M22–M23 | 引用校验通过后创建分享链接（范围、有效期） | 分享入口生成 |
| M24–M25 | 生成导出完成通知 | 提供带引用的导出结果与分享入口 |

> 说明：M04–M05、M20–M21 属异常分支，见图面 `alt` 段落，编号与 `autonumber` 序号一致。

## 3. 关键分支及结果状态

| 触发条件 | 处理与状态 | 图中位置 |
|---|---|---|
| 原文定位失效 | 拒绝保存无锚点的笔记，提示重新选择原文片段 | M04–M05 |
| 笔记引用了回答结论 | 由引用向回答结果核验来源与定位 | M12–M13 |
| 部分引用定位失效 | 导出时返回失效项并标记待复核，不静默丢弃 | M20–M21 |
| 分享范围越权 | 拒绝生成分享链接 | 见 §1 约束 |

## 4. 命名与图面约定

图中使用《01-业务对象清单》的“内容块、笔记模板、笔记、批注、标签、引用、回答结果、分享链接、通知”等名称；“笔记界面、笔记控制器”是交互用边界／控制对象，不进业务对象清单。“分享链接”只对用户有权访问的笔记与文档范围生效，不产生对外公开条目。
