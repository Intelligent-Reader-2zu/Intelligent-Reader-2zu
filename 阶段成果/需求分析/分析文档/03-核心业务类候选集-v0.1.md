# 智能笔记助手需求分析｜核心业务类候选集 v0.1

- 项目：智能笔记助手
- 阶段：需求分析
- 版本：v0.1
- 编制时间：2026-10-23
- 用途：作为核心业务类图的第一版骨架

## 1. 设计原则

1. 这里的“类”是**业务分析类**，不是代码类。
2. 只保留能支撑业务语义的主属性与主职责，不写技术实现属性。
3. 本轮优先服务四张核心图：一张核心业务类图 + 三张关键时序图。

## 2. 类候选分层

### 2.1 核心实体类

| 类名 | 主职责 | 建议保留的主属性 |
|---|---|---|
| 用户 | 发起导入、检索、笔记保存与导出等业务动作 | user_id、角色、显示名、状态 |
| 工作区 | 承载一组文档、策略与成员范围 | workspace_id、名称、范围说明 |
| 文档空间 | 管理某个工作区下的资料集合 | space_id、名称、授权范围 |
| 文档 | 表示一份被纳入系统管理的资料 | document_id、标题、格式、敏感级别、授权状态 |
| 文档版本 | 表示文档在某一时刻的稳定内容快照 | version_id、导入时间、来源哈希、是否失效 |
| 内容块 | 表示文档中可检索、可引用的最小内容单元 | block_id、类型、文本片段、章节路径、置信度 |
| 笔记模板 | 表示保存笔记时采用的字段与输出格式约定 | template_id、类型、字段定义、输出格式 |
| 批注 | 表示用户锚定在原文或回答上的定位性说明 | annotation_id、锚定位置、批注文本、创建时间 |
| 标签 | 表示用户为笔记、文档附加的分类标记 | tag_id、名称 |
| 分享链接 | 表示对指定笔记或文档范围生成的可访问入口 | share_id、范围、有效期、访问权限 |
| 检索请求 | 表示用户发起的一次检索/问答/摘要请求 | query_id、请求文本、请求类型、创建时间 |
| 文档集合 | 表示用户显式选定的一组检索范围对象 | set_id、选择范围 |
| 证据 | 表示支撑结论的原文证据 | evidence_id、定位状态、契约状态 |
| 回答结果 | 表示系统返回给用户的问答或摘要结果 | answer_id、状态、是否待复核、生成时间 |
| 引用 | 表示回答结果到原文证据的绑定关系 | citation_id、页码/章节、定位符、引用文本 |
| 笔记 | 表示用户沉淀的个人记录 | note_id、类型、正文、标签、创建时间 |

### 2.2 控制/过程类

| 类名 | 主职责 | 建议保留的主属性 |
|---|---|---|
| 解析任务 | 负责文档解析与切块过程 | task_id、状态、警告信息 |
| 索引任务 | 负责索引建立过程 | run_id、状态、引擎版本 |
| 索引 | 承载检索阶段实际使用的索引结果 | index_id、索引类型、建立状态、是否失效 |

### 2.3 规则/支撑类

| 类名 | 主职责 | 建议保留的主属性 |
|---|---|---|
| 权限规则 | 定义谁对哪些资源拥有哪些操作权限 | rule_id、主体、资源、动作、规则版本 |
| 策略 | 统一约束引用要求、外发确认、审核门槛等规则 | policy_id、版本、引用要求、审核门槛 |
| 模型配置 | 控制调用什么模型及是否允许云端能力 | config_id、模型提供方、模型名、是否允许云端 |
| 通知 | 承载系统回传给用户的结果提示 | notification_id、类型、资源引用、已读状态 |
| 审计事件 | 记录关键业务动作，支撑可追溯性 | event_id、事件类型、行为人、资源引用、发生时间 |

## 4. 关键关系草稿

> 这一节不是最终 UML 语法，只是先把你明天画类图时最容易卡住的关系说清。

| 编号 | 关系草稿 | 说明 |
|---|---|---|
| R-01 | 工作区 关联 多个 用户 | 一名用户可参与多个工作区；一个工作区至少有成员 |
| R-02 | 工作区 聚合 文档空间 | 工作区是文档组织边界 |
| R-03 | 文档空间 聚合 多个 文档 | 文档空间负责资料归类 |
| R-04 | 文档 组成 多个 文档版本 | 文档版本支撑回溯与失效传播 |
| R-05 | 文档版本 组成 多个 内容块 | 内容块是检索与引用的基础 |
| R-06 | 文档版本 关联 索引/索引任务 | 入库完成后才能进入可检索状态 |
| R-07 | 用户 发起 检索请求 | 检索请求是行为入口 |
| R-08 | 检索请求 可作用于 0..1 个 文档集合 | 防止默认跨库检索 |
| R-09 | 检索请求 产生 回答结果 | 普通检索可直接返回候选结果；问答/摘要生成回答结果 |
| R-10 | 回答结果 关联 多个 证据 | 结论必须有依据 |
| R-11 | 回答结果 组成 多个 引用 | 关键结论要能回到原文 |
| R-12 | 引用 指向 证据，再定位到 内容块/文档版本 | 保证可回页、可回章节、可回原文 |
| R-13 | 用户 创建 多个 笔记 | 笔记可锚定原文或回答结果 |
| R-14 | 笔记 依据 0..1 个 笔记模板 | 无模板时取默认字段与输出格式 |
| R-15 | 笔记 附带 多个 批注 | 批注锚定在原文或回答上 |
| R-16 | 笔记 关联 多个 标签 | 支撑按标签检索与组织 |
| R-17 | 笔记 生成 多个 分享链接 | 分享链接的生效范围受权限规则约束 |
| R-18 | 引用 关联 回答结果 | 引用用于核验结论来源与定位 |
| R-19 | 权限规则 约束 文档、笔记、分享链接、检索请求 | 权限过滤必须先于检索、导出与分享动作 |
| R-20 | 审计事件 记录 导入、笔记保存、导出、检索等关键动作 | 支撑可追溯性说明 |
