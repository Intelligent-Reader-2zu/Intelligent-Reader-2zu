# TECH-STRUCT-012-R01 外部代表样本版面风险探针

日期：2026-09-29  
范围：从已核验外部样本中抽取代表性 PDF/HTML，观察多栏、目录、标题、表格、代码和锚点等版面风险信号。

## 1. 样本

| 样本 | 类型 | 选择理由 |
|---|---|---|
| `OPEN-003` | NIST PDF | 技术报告、目录、表格和脚注候选 |
| `OPEN-010` | Docling 技术报告 PDF | 双栏、图表、公式和参考文献 |
| `OPEN-011` | LayoutLMv3 论文 PDF | 双栏、图表、公式和引用 |
| `WEB-001` | W3C WebAuthn HTML | 大型规范、代码、表格、导航 |
| `WEB-002` | RFC 9110 HTML | 大型规范、锚点、代码和参考文献 |
| `WEB-004` | OpenStax HTML | 教材章节、混合内容和网页脚本 |

## 2. 方法

脚本：`scripts/probe_external_layout.py`  
结果：`results/text-structure/external-layout-probe.json`

PDF 探针读取内嵌目录，并按每页文字的 x 坐标聚类，给出疑似多栏页比例。HTML 探针统计 DOM 标题、标题 ID 唯一率、表格、代码、锚点、导航、article、script 和 style。所有指标都是样本分层信号，不是金标准评分。

## 3. 初步用途

1. `OPEN-010/011` 适合作为双栏阅读顺序和公式/图表标注样本；应逐页确认跨栏标题、参考文献和图注是否被正确分组。
2. `OPEN-003` 和其他 NIST PDF 适合作为长篇目录、页眉页脚、表格和附录样本；不能只依赖 PDF 内嵌目录，因为正文标题和目录条目可能存在差异。
3. `WEB-001/002` 适合作为规范型网页正文抽取样本，但大型 DOM 的导航、脚本生成块和引用锚点必须与正文分层。
4. `WEB-004` 适合作为教材网页样本，需检查图片说明、章节导航、版本信息和动态脚本是否污染正文。

## 4. 约束

多栏页探针只说明页面具有多个 x 坐标簇，不能证明阅读顺序；HTML 标题计数也可能包含导航和生成内容。下一步应从这些样本中人工标注少量页面/章节，形成可复核金标准，再运行标题层级、阅读顺序、表格结构和 DOM 定位指标。
