# TECH-STRUCT-010-R01 下游目录、导航与证据定位准备度

日期：2026-09-29  
范围：统一结构 IR 对目录生成、章节路径、固定证据查询和原始位置回溯的支持度检查。

## 1. 实验目的

验证结构识别结果是否已经具备下游产品能力所需的最小字段：

- 标题是否有唯一元素 ID、非空标题路径和有效父节点，可以生成目录树；
- 固定查询命中后，标题路径是否保留；
- PDF 是否仍保留物理页码和 bbox，Markdown 是否保留源行，HTML 是否保留唯一 DOM selector；
- 把“字段链路没有丢失”与“真实检索/问答效果”明确分开。

本实验不模拟 UI 点击，不评估向量检索排序，也不评估答案语义正确性。

## 2. 方法和输入

脚本：`scripts/score_structure_tasks.py`  
结果：`ir/task-score.json`  

输入为已生成的统一 IR 和样本固定查询标注：

| 样本 | 格式 | 解析器 | 主要检查 |
|---|---|---|---|
| `SELF-001` | PDF | Docling IR | 标题、表格/脚注文字、页码和 bbox |
| `SELF-002` | PDF | Docling IR | 双栏标题、参考文献、跨页位置 |
| `SELF-003` | PDF | Docling IR | 公式、合并单元格、公式/表格证据 |
| `SELF-008` | Markdown | markdown-it-py 扩展 IR | 标题路径、表格、脚注和行号 |
| `SELF-012` | HTML | BeautifulSoup DOM baseline | 标题、表格、正文和 selector |

目录准备度 `toc_ready` 同时要求：至少一个标题、标题 ID 唯一、每个标题有非空路径、父节点（如有）存在。证据查询先按归一化文本匹配元素，再检查标题路径和位置字段。

|---|---:|---:|---:|---:|---:|---:|
| `SELF-001` PDF | 3 | true | 1.00 | 1.00 | 1.00 | N/A |
| `SELF-002` PDF | 6 | true | 1.00 | 1.00 | 1.00 | N/A |

### 3.1 可以确认的事实

1. 当前 5 份样本的 IR 字段足以生成最小目录树：标题 ID、标题路径和父子关系在适配过程中没有丢失。
2. 固定查询命中的元素仍能回到标题路径；PDF 元素仍带物理页码和 bbox，Markdown 元素仍带源行，HTML 元素仍带唯一 selector。
3. 表格单元格和公式对象可以作为证据元素被命中，而不必先降级成普通段落。

### 3.2 不能由本实验推出的结论

- `query_recall=1.0` 只表示预先指定的关键词在样本中找到对应元素，不等于开放域检索 Recall、MRR 或 nDCG；
- `toc_ready=true` 只表示字段和关系满足接口约束，不等于标题层级、阅读顺序或目录文本已经人工验收正确；
- `location_retention=1.0` 只表示已有位置字段没有在映射中丢失，不等于 bbox 一定覆盖完整证据，也不等于用户点击后能高亮；
- HTML selector 结果只覆盖静态快照，不覆盖 SPA 动态内容、iframe、shadow DOM、登录态和页面版本漂移。

## 4. 对产品链路的意义

建议产品先使用统一 JSON IR 生成目录和引用对象，再按格式派生定位方式：

| 格式 | 首选定位 | 位置缺失时的降级 |
|---|---|---|
| PDF | `physical_page + bbox + element_id` | 页码 + 标题路径 + 文本片段；提示需原页核验 |
| DOCX | 固定渲染器生成的页码/bbox | 标题路径 + 段落序号 + 字符偏移 |
| Markdown | `source_line_start/end + element_id` | 字符偏移 + 原文片段 |
| HTML | 唯一 `source_selector`/锚点 + 文档哈希 | 标题路径 + 文本片段 + 原始 URL/快照 |

目录、检索和问答应共享同一 `element_id` 与 `heading_path`。结构置信度低时，检索可以降权，但不得静默删除；严格引用模式应要求存在可回溯位置，公式、表格和脚注则应保留其元素类型和证据资产。

4. 增加开放域检索和问答评测，报告 Recall@k、MRR/nDCG、证据块命中率和引用高亮覆盖率。
