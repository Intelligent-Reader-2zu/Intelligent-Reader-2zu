# TECH-DOC-007-R02 非 OCR 结构复测

日期：2026-09-24  
实验边界：仅处理文本层 PDF；不执行 OCR、不调用云服务、不评估检索或问答质量。

## 已完成

- 使用 PyMuPDF 1.25.3 输出 `DICT` 和 `RAWDICT`，保留页、block、line、span、字符和 bbox：见 `pymupdf/SELF-*.json`。
- 对 `SELF-001` 至 `SELF-003` 执行固定查询和预登记证据片段的自动检查：结果见 `automatic-score.json`。
- 三个样本的固定证据片段命中率均为 `1.0`。该指标只证明预登记片段仍可检索，不是结构 F1。
- 渲染并复核 `SELF-001`、`SELF-002`、`SELF-003` 页面，结果保存在 `rendered/`。
- 生成人工结构标注说明和 JSON 模板：见 `MANUAL-ANNOTATION-TEMPLATE.md` 和 `manual-annotations/README.md`。

## 样本有效性

`SELF-001` 可用于单栏文本、标题、段落、页眉页脚、脚注和基础表格标注。`SELF-003` 可用于基础表格和公式“是否出现”检查，但不能仅凭当前样本证明公式对象或合并单元格结构恢复。`SELF-002` 初版曾因表格越界且正文未进入右栏而无效；现已重新生成。新版页面包含跨栏标题区、左栏正文及完整表格、右栏正文和参考文献，表格未越界，可用于双栏阅读顺序和基础表格网格标注。新版源文件 SHA-256 以结果 JSON 为准。

## 人工标注和评分状态

`SELF-001`、`SELF-002`、`SELF-003` 已通过自然语言问答完成用户确认，并回填阅读顺序、自然段边界、标题级别、页眉页脚/脚注类别、表格网格和 bbox。评分结果见 `TECH-DOC-007-R02-MANUAL-SCORE.md` 和 `manual-score.json`。

## 对一期范围的影响

本轮继续支持“先建立文本层、页级和 bbox 证据，再讨论下游检索/引用”的判断。PyMuPDF 的原始结构可作为坐标低层对照，Docling 可提供结构候选但需要标题、脚注和表格校验，Tika 可作为 Java 纯文本基线。扫描 PDF 和 OCR 仍保持在下一调研环节。
