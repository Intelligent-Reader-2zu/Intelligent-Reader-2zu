# TECH-STRUCT-014-R01 外部 PDF 代表页视觉复核

日期：2026-09-29  
范围：对外部 PDF 标注队列中的代表页进行渲染和人工视觉复核，检查版面风险探针是否足以筛选双栏、图表和正文边界。

## 1. 复核页面

| 样本 | 页面 | 视觉观察 |
|---|---:|---|
| `OPEN-010` | 1 | 封面/摘要/引言为单栏主结构，包含图形元素、页眉页脚和标题；不应简单视为全篇双栏 |
| `OPEN-010` | 3 | 单栏图文页，图注和小节标题需要与正文分开；同一文档页面布局发生变化 |
| `OPEN-011` | 1 | 明显双栏：左栏摘要/关键词/引言，右栏图和引言正文；页脚还有贡献说明与版权文字 |
| `OPEN-011` | 3 | 明显双栏，跨栏图及图注位于上方，正文在图注后按左右栏继续；公式和段落边界需要单独标注 |

渲染文件位于 `results/text-structure/rendered/external/`，使用 Poppler `pdftoppm` 生成。渲染过程中出现字体映射警告，但 PNG 已成功生成并可供视觉核对。

## 2. 与自动探针的差异

`TECH-STRUCT-012-R01` 的 x 坐标聚类结果为：`OPEN-010` 疑似多栏页比例 `0.1111`，`OPEN-011` 为 `0.0`。视觉复核显示 `OPEN-011` 至少第 1、3 页明显双栏，因此 `0.0` 是一个假阴性。

原因是简单 x 坐标聚类没有建模栏宽、文字行的连续性、跨栏图和页边距；双栏页面中的图、标题和页脚会改变 x 坐标分布，使固定阈值失效。该探针不能用于自动标注 `column_id` 或阅读顺序。

## 3. 对实验设计的修正

1. 页面是否双栏必须以渲染视觉检查或版面模型候选为准，x 坐标探针只保留为“待人工复核”提示。
2. 同一文档应按页面标注布局类型，不能给整份 PDF 只分配一个 `layout_mode`；`OPEN-010` 已显示页面间布局变化。
3. 双栏金标准需要记录栏区域、跨栏标题/图注、左栏到右栏的阅读顺序和页脚家具元素。
4. 评测中将“栏检测正确率”和“阅读顺序正确率”分开；前者正确不代表后者正确。

## 4. 结论边界

本轮只验证样本选择启发式的可靠性，不报告解析器准确率。真正的结构评分仍需要人工标注上述页面的元素、bbox、阅读顺序、标题层级和图注/公式关系。
