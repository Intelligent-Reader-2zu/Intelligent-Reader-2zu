- 版本：V0.3（目标并入 SPEC V1.1 附录 A）
- 编制：2 组 · 郭谦
- 日期：2026-10-19
- 基线：1 组《SPEC V1.0》
- 编号口径：状态名取自《[编号规则与术语表](./编号规则与术语表.md)》§1.4；错误码前缀见本文件 §1

## 0. 为什么需要这张表

SPEC V1.0 在三处**要求**使用错误码，却**没有定义任何一个取值**：

| 出处 | 原文要求 |
|---|---|
| SPEC §3.1 | 状态转换必须记录时间、解析器版本、配置哈希、**错误码**和重试次数 |
| SPEC §6 | `ExportJob` 必须记录 `format`、`scope`、`target_path`、`status`、`created_at` 和 **`error`** |
| SPEC §7 | `GET /documents/{id}/status` 返回状态、进度、警告和**错误码** |

结果是：状态机有值、失败路径有描述，但"失败"落到哪个可枚举、可断言、可进测试用例的标识上，基线没有给。本表把它补上，作为 SPEC V1.1 的**附录 A**。

**本表只做"把 SPEC 已描述的失败路径编号化"，不新增任何失败路径。** 每条错误码都以 SPEC 原文为唯一依据。

## 1. 编号归属（需登记）

`ERR-` 为 **2 组新增编号空间**，格式 `ERR-<模块号><序号>`：

> ✅ **已登记（2026-10-19）**：`ERR-` 已补入《[编号规则与术语表](./编号规则与术语表.md)》§1.1 编号前缀总表，并新增 §1.6「错误码编号」冻结前缀与段位划分。术语表 §1.6 只冻结**前缀与段位**，**取值语义以本文件为唯一出处**。

## 2. 通用约定

- **结果状态**一律使用术语表 §1.4 的冻结状态名；`—` 表示该错误不落到状态机，只返回错误响应（多为**前置校验失败**，尚未产生状态对象）。
- **重试**三态：
  - `不可重试`——条件不可变（如格式不支持）；
  - `可重试`——原样重试有效（如解析失败、模型超时）；
  - `改善后可重试`——需用户先改条件（权限、范围、路径、网络）。
- **可见性**：建议对用户只展示语义提示，错误码仅进日志与 `/status` 接口（见 §6）。

## 4. 与 SPEC §5.2 降级规则的对应

SPEC §5.2 的 5 条降级规则 → 状态 → 错误码：

| SPEC §5.2 条件 | 结果状态 | 由哪些错误码触发 |
|---|---|---|
| 无网络或用户拒绝外发 | `local_evidence_only` | `ERR-306`、`ERR-401`、`ERR-503` |
| 证据覆盖不足 | `needs_human_review` | `ERR-509` |
| 模型超时或失败 | `model_failed` | `ERR-501`、`ERR-502` |
| 引用定位失败 | `citation_invalid` | `ERR-504`、`ERR-505`、`ERR-506`、`ERR-507`、`ERR-508` |
| 证据过期或撤权 | `stale` | `ERR-303`、`ERR-304`、`ERR-305` |

**5 条规则全部有错误码落地，无缺口、无溢出**（错误码不产生 §5.2 之外的新状态）。

## 5. 与 SPEC §8 测试组的对应

SPEC §8 定义了 5 个测试组，每组的最小用例应覆盖以下错误码：

| SPEC §8 测试组 | 最小用例 | 应覆盖错误码 |
|---|---|---|
| 解析 | 文本 PDF、扫描 PDF、DOCX、Markdown、低置信样本 | `ERR-201`、`ERR-202`、`ERR-203`、`ERR-204`、`ERR-205`、`ERR-206`、`ERR-207` |
| 权限 | 授权 / 撤权 / 未授权文档集合 | `ERR-301`、`ERR-302`、`ERR-303`、`ERR-307` |
| 引用 | 页码、bbox、版本变化、无依据问题 | `ERR-304`、`ERR-505`、`ERR-506`、`ERR-507`、`ERR-508`、`ERR-509`、`ERR-510` |
| 外发 | 确认、拒绝、网络断开 | `ERR-401`、`ERR-402`、`ERR-403`、`ERR-404`、`ERR-502`、`ERR-503` |
| 导出 | 指定路径、无权限路径、源文件差分 | `ERR-603`、`ERR-604`、`ERR-605`、`ERR-606`、`ERR-607` |
