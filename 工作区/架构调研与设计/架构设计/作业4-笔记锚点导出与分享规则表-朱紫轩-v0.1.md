## 1. 职责范围与边界

本子稿细化逻辑视图中“笔记、导出与分享”模块的规则约束，覆盖从“保存为笔记”到“导出/分享”的完整链路。

**新增设计输入（组长 2026-11-11 补充）**：① 系统包含 PC App 与手机 App，功能范围一致；② 离线时两端均可用本地文档及核心阅读、检索、笔记功能；③ 个人账号下的阅读进度、笔记等实体经云端同步，**原文文件本体不同步**；④ 联网时可用 AI 辅助功能。本稿按此方向补充本模块的数据分布与断网、冲突处理规则。

本稿只记录模块级规则、数据分布与待决项；**不单独定稿部署图、同步方案或共享 ADR**，待子稿齐后由组长统一评审整合。明确**不负责**：检索召回、证据构造与外发门控（廖欣豪子稿）；文档导入、解析与索引任务（程禹轩子稿）；技术类别候选与部署假设矩阵（汪昊子稿）；阅读进度等非本模块实体的同步归属。接收者认证的底层实现（登录体系等）属实现设计，本稿只记录规则边界与未决项。

## 2. 一页规则表

| 编号 | 环节 | 触发条件 | 系统行为（规则） | 状态 / 完成信号 | 依赖模块 | 失败路径与处理 | 技术未决项 |
|---|---|---|---|---|---|---|---|
| R-01 | 保存前锚点校验 | 用户从原文选区发起“保存为笔记”（M01–M02） | ① 校验当前用户对来源文档/版本仍有访问权；② 回源校验原文定位在当前版本仍有效。任一不满足 → **拒绝保存**，返回失效原因，提示重新选择原文片段（M04–M05）；不自动跳转到新版本替代 | 无有效锚点的笔记保存成功数为 0（ASR-06）；校验先于笔记落库（M08） | 身份权限与策略门；文档/文档版本/内容块；笔记控制器 | 撤权、版本失效、内容块被删除 → 拒绝保存并提示重选 | ① “定位有效”的判定粒度（页/章节/块/字符级，与 ASR-03 逐格式精度同源）；② 校验通过后、落库前版本失效的并发竞态：由事务还是落库前重校验兜底 |
| R-02 | 保存时引用核验 | 笔记引用了回答结论（M12–M13） | 由引用向回答结果核验结论来源与原文定位；核验通过才可作为“已核验”引用随笔记落库；模型生成的引用不自动可信（ADR-001 执行约束） | 引用状态可追溯：未关联 → 已关联 → 已核验 / 失效（流程脚本 §3.4） | 检索证据与回答模块（证据契约、引用校验）；回答结果 | 来源无法核验、定位缺失 → 标记待复核，或不以“已核验”状态保存 | 核验通过后源版本更新/重解析导致引用变 stale 的传播时机与责任模块（与场景二共用，见《关键场景走查》§5） |
| R-03 | 导出前引用复核 | 用户选定笔记范围发起导出/分享（M16–M19） | 汇总笔记、批注、标签及引用与原文定位，**逐项复核**；有效项随导出结果带出，失效项显式返回并标记待复核，**不静默丢弃**（M20–M21）；导出的每一条结论都带原文定位（流程脚本 §4） | 导出中“未报告而被丢弃的失效项数”为 0（ASR-06） | 检索证据与回答模块（引用校验）；持久化 | 部分引用失效 → 返回失效项清单 + 待复核标记，其余有效内容照常导出；导出格式不支持某级定位 → 降级说明（页/章节/块级） | ① 导出格式及各格式下定位的表达方式；② “待复核”状态是否回写引用/笔记对象；③ 大笔记集导出是否走异步任务边界（与导入任务边界口径一致） |
| R-04 | 分享范围校验（创建时） | 用户发起分享（M22–M23） | 请求范围必须 ⊆ 用户当前有权访问的笔记与文档范围；**越权范围不得生成链接**；分享链接只对有权笔记与文档范围生效，不产生对外公开条目（流程脚本 §1、§4） | 越权范围进入分享链接的次数为 0（ASR-06）；链接创建前完成范围校验 | 身份权限与策略门；策略（BO-24）；权限规则（BO-10） | 范围越权 → 拒绝创建链接并说明原因 | 请求范围内部分资源撤权时：整体拒绝，还是收缩范围后允许分享 |
| R-05 | 分享访问认证（访问时） | 接收者打开分享链接 | 访问时**再次**校验：接收者身份/认证方式、链接状态（已生效）、资源当前权限；“拥有链接”不等于“拥有资源权限”（《关键场景走查》§4 结论） | 无权或已失效访问不能读取内容；权限在创建与访问两处均校验 | 身份权限与策略门 | 认证失败、链接已失效、资源已撤权 → 拒绝访问并提示 | ① 接收者认证方式（系统登录/密码/仅凭链接）；② 可选访问者范围（指定用户/工作组成员/任何持有链接者）；③ 是否允许转发 |
| R-06 | 有效期与撤销 | 链接超过有效期；作者撤销分享 | 分享链接状态机：未创建 → 已生效 → 已过期 / 已撤销（流程脚本 §3.4）；到期自动失效；撤销后立即失效；每次访问复核有效期与撤销状态 | 已过期/已撤销链接不能访问内容；链接状态、范围、有效期可查询、可撤销 | 笔记模块（分享链接）；身份权限与策略门 | 到期/撤销后访问 → 拒绝并提示链接失效 | ① 有效期默认值与可选档位；② 是否允许续期、修改范围；③ 撤销粒度（链接级/资源级）；④ 撤销后接收者已缓存/已导出副本的处理边界 |
| R-07 | 通知与业务状态一致 | 保存/导出完成通知发送失败 | 通知失败不反向改变已完成的业务状态（ASR-09 部分已定，与导入脚本同口径） | 通知失败时笔记/分享链接的业务状态不回滚；失败阶段可识别 | 通知（BO-21，跨流程边界对象，不入类图） | 通知渠道失败 → 记录失败，业务状态保持 | 通知失败是否留痕，联动审计范围未决项（BO-22 暂不入类图） |
| R-08 | 一致持久化 | 笔记、锚点、批注、标签、引用、分享链接落库 | 笔记、来源版本、锚点与引用关系**一致持久化**（《关键场景走查》§4 结论）；部分失败不产生“显示已保存但缺锚点/缺引用关系”的笔记 | 不存在锚点或引用关系缺失却显示已保存的笔记 | 适配器与持久化端口；持久化角色（技术待定） | 落库中途失败 → 整体失败或进入可补偿的明确状态 | 事务边界与部分失败补偿策略（实现设计阶段；具体存储技术由汪昊技术矩阵子稿比较） |
| R-09 | 双端功能范围一致 | PC App 与手机 App 运行 | 两端执行同一套规则（R-01～R-08、R-10～R-14），功能范围一致；平台差异仅限界面交互 | 同一账号在任一端的行为不变量一致，无单端专属功能缺口 | 客户端（PC/手机形态）；笔记模块 | 某端实现与规则表不符 → 按规则表对齐（一致性检查） | 无（约束性输入） |
| R-10 | 离线可用 | 设备断网 | 本机数据与本地文档支撑核心笔记能力：保存/编辑笔记、批注、标签、模板、本地导出均可用；阅读与检索依赖文档/检索模块，本稿保证笔记链路不阻断；本地修改进入待同步状态 | 断网时笔记保存与本地导出主路径可用；恢复联网后可同步（ASR-05 离线降级口径） | 本机持久化；笔记模块；文档/检索模块（仅依赖） | 断网中使用需云端的能力 → 明确提示需联网（R-13），不伪装成功 | 待同步队列的容量、持久化与重试（归组长统一同步方案） |
| R-11 | 云端同步范围 | 同步集合内实体发生变化 | 笔记、批注、标签、引用记录、笔记模板、分享链接定义经云端在个人账号各端同步；**原文文件本体、文档版本、解析产物、索引不上云** | 同步实体各端最终一致；原文文件本体不出域 | 云端同步（技术未定，不属本稿设计） | 误将原文文件当同步内容 → 拒绝，仅同步元数据 | 同步时机、顺序与一致性模型（归组长统一同步方案） |
| R-12 | 跨端锚点校验 | 笔记同步到某端，该端无来源文档/版本（原文不同步所致） | 笔记正文可读；锚点/引用标记“本端不可回溯/待复核”，不静默丢弃、不显示为有效引用；该端导入同一文档版本后重新校验并恢复状态 | 跨端“待复核”锚点可识别；无对应文档版本时不虚增“已核验”引用（ASR-06 扩展场景） | 本机文档/文档版本；笔记模块 | 用户点击不可回溯的引用 → 提示本端缺失源文档版本并指引导入 | 重新校验的触发时机与批量恢复流程 |
| R-13 | 断网时的分享 | 断网中创建/撤销分享 | 分享链接的创建、访问、撤销依赖云端权威状态 → 离线请求排队，联网后生效；本地导出不受影响；接收他人分享需联网 | 离线创建的分享不伪装为“已生效”；排队请求状态可见、可重试、可取消 | 云端权威状态；身份权限与策略门 | 请求长期排队无网 → 保持待处理并可取消 | 排队保留期限与取消语义 |
| R-14 | 冲突处理 | 同一实体双端并发修改（含断网恢复后） | 不静默覆盖、不静默丢弃；冲突显式可见，至少保留双方内容可识别；分享链接状态以云端权威为准 | 冲突场景不丢失用户内容；冲突项可被用户或规则显式解决 | 云端同步；笔记模块 | 冲突未被识别 → 兜底保留双方版本，不任选其一覆盖 | 合并策略（最后写入/字段级/用户选择）与冲突解决方式（归组长同步方案评审，本稿不设计） |

## 3. 本模块数据分布与断网、冲突处理

### 3.1 数据分布（本机 vs 云端同步）

| 实体/数据 | 本机留存 | 云端同步 | 备注 |
|---|---|---|---|
| 笔记（正文、类型、标签绑定） | 是，离线可读可改 | 是 | 个人账号实体 |
| 批注 | 是 | 是 | 同步文本与锚定描述；锚定有效性仅本机可校验 |
| 标签 | 是 | 是 | |
| 笔记模板 | 是 | 是 | 用户自建模板同步；系统默认模板随版本内置，不同步 |
| 引用记录（定位描述、引用文本） | 是 | 是 | 同步的是引用记录；定位有效性只能在本机校验（R-12） |
| 分享链接（范围、有效期、状态） | 本地缓存 | 是（云端权威状态） | 创建/撤销须在线执行（R-13）；本机缓存与云端冲突以云端为准（R-14） |
| 原文文件、文档版本、解析产物、内容块、索引 | 是 | **否** | 原文文件本体不同步；各端自行导入同一文档版本后方可校验锚点 |
| 阅读进度 | 本机可用 | 是 | 属阅读/文档模块实体，与笔记同属个人账号同步实体集；本稿不重复定义，仅记录边界 |

### 3.2 断网行为

| 能力 | 断网可用 | 规则 |
|---|---|---|
| 阅读本地文档、检索本地索引 | 是 | 依赖文档/检索模块（程禹轩/廖欣豪子稿）；本稿保证笔记链路不阻断 |
| 保存/编辑笔记、批注、标签、模板 | 是 | 先写本机并进入待同步状态（R-10）；不得因无网拒绝保存 |
| 引用核验（保存时） | 是（本机有源文档时） | 本机无源文档版本时按 R-12 标记“本端不可回溯” |
| 本地导出 | 是 | 生成带定位的本机导出结果；复核规则 R-03 不变 |
| 分享链接创建/撤销 | 否 | 请求排队，联网后生效；状态可见可取消（R-13） |
| 接收他人分享链接 | 否 | 访问校验依赖云端（R-05） |

### 3.3 冲突场景与模块规则（不设计同步方案）

| 场景 | 模块规则（不变量） | 具体策略状态 |
|---|---|---|
| 同一笔记双端并发编辑 | 不静默覆盖、不丢内容；冲突时至少保留双方版本并可识别 | 合并策略待组长同步方案评审（R-14 未决项） |
| 笔记删除 vs 他端新增批注 | 不产生静默悬挂的“孤儿批注”；删除与新增冲突需显式处理 | 同上 |
| 分享链接撤销 vs 本机缓存“已生效” | 以云端权威状态为准；本机缓存失效后重新校验 | 缓存失效时机（TTL/在线校验）待定 |
| 模板并发修改 | 同 R-14 不变量 | 待组长同步方案评审 |
| 跨端锚点状态 | 各端独立校验；“待复核”状态可随同步带到他端，但不伪装为已核验 | 重新校验触发时机待定 |
| 断网期间累计多条本地修改 | 按创建顺序保序同步；失败可重试，不部分静默丢弃 | 队列与幂等机制归同步方案，本稿不设计 |

## 5. 主要失败路径汇总

| 故障 | 责任模块 | 状态变化 | 用户可见结果 | 关键不变量 |
|---|---|---|---|---|
| 原文锚点失效/版本不匹配 | 笔记控制器 + 内容块 | 不落库 | 提示重新选择原文片段 | 无锚点笔记数 = 0 |
| 笔记引用结论来源无法核验 | 引用 + 回答结果 | 引用标记待复核/失效 | 不以已核验状态保存 | 引用有效性由系统验证 |
| 导出时部分引用定位失效 | 笔记控制器 + 引用 | 失效项标记待复核 | 失效项清单 + 其余内容导出 | 未报告丢弃数 = 0 |
| 分享范围越权 | 权限与策略门 | 不创建链接 | 拒绝并说明原因 | 越权链接数 = 0 |
| 链接过期/被撤销后访问 | 身份权限与策略门 | 访问被拒 | 提示链接失效 | 不能读取内容 |
| 通知发送失败 | 通知（边界对象） | 业务状态不回滚 | 可识别失败阶段 | 已完成业务状态不变 |
| 断网时保存/编辑笔记 | 笔记模块 + 本机持久化 | 写入本机待同步 | 正常保存，恢复联网后同步 | 无网不拒绝保存 |
| 跨端缺失源文档版本 | 笔记模块 + 本机文档 | 锚点标记“本端不可回溯” | 正文可读；引用提示缺失源文档并指引导入 | 不虚增已核验引用 |
| 断网时创建/撤销分享 | 云端权威状态 | 请求排队待处理 | 提示需联网或已排队，可取消 | 不伪装为已生效 |
| 双端并发修改冲突 | 云端同步 + 笔记模块 | 保留双方版本待解决 | 冲突显式可见 | 不静默覆盖/丢弃 |
