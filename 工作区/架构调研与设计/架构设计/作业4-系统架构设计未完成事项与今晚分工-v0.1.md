## 2. 建议直接采用的课程作业级基线

本次目标是完成课件要求的系统架构设计，不是承诺交付生产级产品。建议以以下范围作为默认方案；只有发现它与老师已明确的课件要求或需求分析基线冲突时，才针对冲突项调整。老师后续阶段的安排尚未公布，不作为今晚需要预测或解决的问题。

| 设计项 | 建议基线 | 取舍边界 |
|---|---|---|
| 目标场景 | 单用户在个人电脑上进行课程演示；浏览器界面与后端服务运行在同一台设备 | 保留应用层权限、引用和受控导出约束；不实现多人在线协作、实验室服务器、云端集群或高并发部署 |
| 架构风格 | 模块化单体；导入解析、索引、权限策略、检索证据、问答引用、笔记导出保持清楚的逻辑边界 | 不拆微服务；模块边界用于说明职责与便于替换，不代表独立部署 |
| 长任务处理 | 在应用内以后台任务执行，并记录任务阶段和成功/失败状态；中断后可识别并由用户重试 | 不引入独立 worker、Kafka/RabbitMQ 等消息中间件，也不承诺生产级崩溃恢复 |
| 数据与检索 | SQLite 保存元数据、任务和笔记；原文及解析产物保存在本地文件系统；本地全文/BM25 为必需基线，可用 FTS5 做候选实现 | 不部署独立数据库或向量数据库；中文分词与检索质量只按固定课程样本验证 |
| 语义检索 | 作为可插拔增强候选，可用已有 `BAAI/bge-small-zh-v1.5` 小样本结果说明可行性 | 不把小样本结果说成准确率保证；没有必要为课程设计增加独立向量服务 |
| 模型调用 | 核心阅读、全文检索和证据查看在模型关闭时仍可用；外部模型仅作为可禁用适配器，且必须经过证据白名单、策略和本次用户确认 | 不部署本地生成模型，不绑定特定供应商，不承诺外部服务 SLA |
| 文档范围 | 以文本型 PDF、DOCX、Markdown、TXT 为设计基线；扫描件/OCR、复杂表格和公式只说明降级，不承诺精确问答 | 依据已有解析调研和实验，避免把最佳努力支持写成完整能力 |
| 质量验证 | 用已有固定样本验证权限过滤、引用定位、索引失败降级和模型不可用路径；性能记录测试环境与样本规模 | 不设无依据的生产 SLA、容量上限或合规承诺 |

这套基线足以覆盖课件要求的架构风格、部署策略、技术选型、视图和关键场景说明，同时把实现与运维范围控制在学生课程设计能够解释的程度。它是推荐的课程设计剖面，不等于对未来课程任务或最终产品范围作承诺。
